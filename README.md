# 会成长的个人助手

单用户网页助手，使用 Python / Flask / 原生前端，数据保存为 JSON 和 Markdown 文件。需求和阶段安排见 [PLAN.md](PLAN.md)。

## 当前范围

- 网页手动输入或导入 JSON 通知，重复消息检查，原文查看。
- 结合画像与规则调用模型，提取事项、行动、截止/活动时间及不确定内容。
- 围绕选择的通知进行对话，也可以让模型撰写邮件**文本草稿**；没有发送功能。
- 编辑画像与规则，或在对话中使用 `/记住 信息`、`/规则 纠正`、`/查看画像`、`/查看规则`。
- 文件持久化、记忆历史与中断恢复、单实例写入保护、日 API 尝试次数限制。
- v0.2：按任务授权域操作真实 Chromium，自由文本检索、通用控件、失败重试/恢复、进度/取消、通用来源引用和私人分析；真实 Kimi 联调暴露引用与结果质量问题，尚未通过端到端验收。
- v0.3：QQ 收件箱只读增量同步、主题初筛建议、手动细读、摘要与事件表、带来源的画像补充；真实账号最新一封邮件读取、模型分析与只读状态检查通过，新到达聊天样本仍待验收。

Kimi 自行选择导航、点击、检索、筛选、翻页、恢复或报告停止，不再使用固定关键词、招聘路径、必经首页及失败 URL 永久禁令。权限与总预算仍由程序执行；不开放任意 Shell/Python/页面 JS。

尚未实现：任意网站自主操作、附件识别、实时/定时主动推送、普通对话自动提取画像、邮件上下文对话/回复草稿、授权邮件发送、远程安全部署。QQ/微信客户端自动接入已取消，网盘与聊天备份暂缓；权限遵循自动读取、手动分析、按需草稿、写操作单独确认。网页仅本机访问，不代表已能在手机上远程使用。

## 本地启动（WSL / Linux，Python 3.10+）

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -c requirements.lock -e .
.venv/bin/python -m assistant
```

浏览器打开 `http://127.0.0.1:8000`。端口可通过 `--port 8001` 改变。默认演示模式不访问模型，只验证界面和保存流程；不会真实判断相关性或日期。点击“载入合成样例”可开始试用。

当前使用本地开发服务器，不要把监听地址改成公网地址，不要在多 worker 中运行。接入邮箱必须配置单用户访问口令；没有验证生产服务器、TLS 和共享环境隔离，仍不适合直接部署到共享服务器。退出后文件仍保留，下一次启动会读取原有记录。

## 配置真实模型

在启动进程的**同一个终端**设置环境变量，或复制 `.env.example` 为 `.env` 后用编辑器填入配置。`.env` 自动读取，但不会覆盖已经存在的环境变量；修改后需重启程序。

**真实 Key 不能写入 `.env.example`，该文件会进入公开仓库。不要把 Key 发到聊天中。**

```bash
export ASSISTANT_LLM_MODE=api
export ASSISTANT_API_BASE=https://api.moonshot.cn/v1
export ASSISTANT_MODEL=kimi-k2.6
export ASSISTANT_LLM_EXTRA_BODY='{"thinking":{"type":"disabled"}}'
# 通过隐藏输入读取 Key，不将它作为命令写进 shell 历史。
read -r -s -p "API Key: " ASSISTANT_API_KEY
export ASSISTANT_API_KEY
.venv/bin/python -m assistant
```

通知分析与普通对话使用 Chat Completions JSON 输出，不发送 tools。明确发起的网页任务启用浏览器/证据工具，邮件分析启用本地事件/画像工具；模型不能执行任意代码或授予自己写权限。Kimi 参数及工具调用参考 [API 文档](https://platform.kimi.com/docs/api/chat)，换模型时核对参数要求，不盲目沿用 `thinking` 或采样参数。

默认日尝试上限 30 次、单次输出上限 4096 token、超时 60 秒；可通过 `ASSISTANT_DAILY_CALLS`、`ASSISTANT_MAX_TOKENS`、`ASSISTANT_TIMEOUT` 修改。次数限制不是金额预算。失败尝试也计数，可能已被服务商计费；模型 API 失败没有自动重试，浏览动作失败可在任务预算内由模型选择恢复。额度按 `ASSISTANT_TIMEZONE`（默认 Asia/Shanghai）计算，重启不清零。

配置 Key 后也必须明确选择 `api` 模式。API 请求失败不会回退到演示模式。已有演示分析结果需点击“重新分析”才会使用真实模型。

另一个终端中的 `export` 不会改变已经运行的网页服务或 Agent 的环境。若要让 Agent 联调，推荐在本地被忽略的 `.env` 中配置，而不是在对话里提供凭据。

## v0.3 QQ 邮箱：首次启用与验收

只接入一个 QQ 收件箱，使用证书验证的 IMAP TLS 连接；不启用 SMTP。服务地址依据[腾讯邮件连接器说明](https://main.qcloudimg.com/raw/document/product/pdf/1270_46586_cn.pdf)。IMAP 连接不继承 HTTP_PROXY，不改变系统代理或 DNS。

在本地 `.env` 填入以下配置，不要写入 `.env.example` 或发送到聊天：

```dotenv
QQ_IMAP_USER=你的QQ邮箱地址
QQ_IMAP_AUTH_CODE=新生成的授权码
ASSISTANT_ACCESS_TOKEN=本地生成的随机访问口令
ASSISTANT_MAIL_POLL_SECONDS=60
ASSISTANT_CHAT_SELF_NAMES=
```

访问口令至少24字符，建议用 `.venv/bin/python -c 'import secrets; print(secrets.token_urlsafe(32))'` 在自己的终端生成；网页登录使用它，不使用邮箱授权码。真实分析仍需上述 Kimi API 配置。若授权码曾发到聊天或公开位置，先撤销并生成新码。

`ASSISTANT_ACCESS_TOKEN` 只用于保护本地网页中的私人资料，不是模型 Key 或邮箱密码，不发给模型、不放在 URL。保存后需重启服务，用本地 `.env` 中的这个值登录；它不替代远程部署的 TLS。

1. 重启应用、登录，打开“邮箱”，点击启用同步。**首次成功连接只建立当前 UID 基线，不读取已有历史邮件。**
   如需单独验证已有邮件，可点击“导入最新一封已有邮件”并确认；只导入一封，不批量补历史、不自动调用模型、不移动新邮件基线。
2. 在基线建立后向邮箱发送一封新的文本测试邮件，最好包含原聊天日期、说话人、截止时间和一个公开链接。约60秒轮询新邮件标题；可点击立即同步与刷新列表。网页目前不主动推送新内容。
3. 点击主题初筛，模型仅接收待处理邮件的标题、发件人、邮件日期与本人发件提示，每批最多30封，给出细读/待定/建议忽略。建议不是删除，所有邮件仍可手动细读。
4. 点击细读分析，按需读取正文，展示摘要、事件表、时间/行动/原文与待确认项。正文最多24000字符、原始读取最多1MiB，截断明确标记；附件只显示名称，HTML 转纯文本，不加载远程图片。
5. 模型可选择提出画像补充。本人发件地址只作线索，不是身份认证；未配置本人昵称或无法归属时留待手动确认。`ASSISTANT_CHAT_SELF_NAMES` 可配置逗号分隔昵称，原文行以 `昵称：`、`昵称:` 或 `[昵称]` 开头时支持自动补充，并保留来源未验真的标签、原文与记忆版本。模型决定更新内容和时机，不使用语义关键词规则。当前只追加，矛盾归并、过期清理仍待实现。

事件由 `save_mail_analysis` 原生工具结构化提交；程序按模型给出的行号提取原文、校验字段及带时区日期。原文存在不保证结论正确，请复核。不用转发/同步日期冒充原聊天时间。

主动转发的单条群消息或任意纯文本都可分析，不需要昵称/聊天导出格式。说话人不明只影响能否认定为用户事实，不影响提取事项和分析内容。当前用户已确认仍手动初筛/分析，后台不会调用 Kimi。

链接暂不自动访问。结果中可把链接转入现有网页任务，检查 URL 是否含私人信息、确认公开查询范围后再开始；不将邮件正文自动发送给网站。网页结果暂未自动合并回邮件分析。邮件上下文多轮对话和回复草稿还未接上，SMTP 发送仍是后续阶段。

邮件文件与同步状态保存在忽略的 `data/mail/`，目录限制本用户访问。使用只读选择与 `BODY.PEEK`，不标已读、不移动/删除远端邮件；UIDVALIDITY 变化拒绝继续读取，不静默重置基线。后台只同步标题，不调用模型。重启恢复已有基线，修改账号须单独处理原数据，不自动覆盖。

当前本地记录一直保留，没有自动清理或备份；接入真实私人邮件前请确认接受该方式。不要上传 `data/`。已有邮件数据时也必须保留访问口令，不能通过移除邮箱配置使私人记录变成公开。

## v0.2 网页任务（通用核心已实现，真实结果质量待修正）

操作网页使用 Playwright 驱动真实 Chromium，不是让模型生成终端命令。首次安装浏览器后，在启动应用的同一终端设置其路径：

```bash
export PLAYWRIGHT_BROWSERS_PATH="$PWD/data/browser-cache"
.venv/bin/python -m playwright install chromium --no-shell
.venv/bin/python -m assistant
```

Linux 若缺少浏览器系统库，按 Playwright 提示安装；此操作可能需要管理员权限。浏览器二进制不进入 Git。通知/普通问答仍可在没有 Chromium 的情况下使用，只有浏览任务会提示启动失败。

Linux 的 Chromium 截图需要中文字体；本次检查环境没有中文字体，截图会显示方框，但 DOM 中文读取正常。开启视觉前先安装中文字体。通过 Windows 浏览器访问本地网页时使用客户端字体，不依赖 WSL 的截图字体。

在“网页任务”填写起始 HTTPS URL 和一个必填的公开任务目标；私人筛选条件可选，不需要重复填写目标。例如目标可写“查找计算机相关岗位，进入详情，整理岗位名称、地点、要求与来源”，不要只写“不要填写个人信息”等注意事项。确认目标可用于网站检索后模型可自由组织相关检索词，不逐词审批；不要将敏感信息放入公开目标。起始网站自动授权，页面依赖的公网 HTTPS 脚本、样式、图片、字体与媒体自动加载，不需要用户识别或填写 CDN 域名。额外网站/数据接口范围在高级区，通常无需填写；静态资源自动加载不授权其所在网站的页面导航或数据接口，也不是任意网站都能安全操作的承诺。

新 API 使用 `goal` 与可选 `private_conditions`；旧 `request/public_request` 仍兼容，但不能与新字段混用。旧任务记录不改写，也不会把旧私人要求自动公开。升级后重启服务、刷新网页，并新建一个填写完整公开目标的任务；直接重新发起旧任务仍沿用其旧目标。

默认每任务40次模型调用、120次动作、900秒，可用 `ASSISTANT_BROWSER_CALLS`、`ASSISTANT_BROWSER_STEPS`、`ASSISTANT_BROWSER_SECONDS` 调整。共用日额度，开始前显示有效模型预算（本任务上限与日剩余的较小值），不会自动增加日额度。原 `.env` 中的12/300等值仍会覆盖新默认，需自行更新并重启。移除前20页/20份详情限制；观察数量随总动作预算，正文保留受长度保护并支持分段，不宣称覆盖全站。

浏览工具包括观察、链接/URL导航、点击、hover、页面 Escape、自由搜索、滚动、返回、刷新、有限等待、按键、下拉选择、筛选勾选和匿名浏览器重启。普通界面按钮无需命中“关闭/稍后”白名单，仍不强制穿透遮挡；元素装饰性标签变化不会使整个引用失效。`observe_page` 的 `text_start`/`text_length` 支持正文窗口，`read_source` 返回指定位置的编号行。`finish_task` 的 findings/jobs 均可用行号由程序取原文，岗位标题自动取，画像原文引用可省略；旧格式仍兼容。

所有阶段始终提供同一个 `task_goal`，上下文裁剪和工具反馈也保留目标；提示词要求检索与交付围绕目标，不用固定专业关键词限制搜索。浏览阶段不接收原始私人画像/规则或私人筛选条件；`analyze_results` 切到私人分析，此时只有本地证据、结束和清除上下文后返回浏览的工具。新任务若填写私人条件，必须进入分析阶段才能交付，预算收尾时也会先关闭网站动作再提供条件。所有阶段共用总预算；返回浏览不会带入私人分析对话。根据任务预算预留最多3次用于来源读取/收尾/纠正，不突破总额度，纠正也消耗调用；校验一次返回全部问题，编号引用要求对应行已提供给模型。`search_source` 可定位保存的关键词片段，避免猜行号。原文存在仍不保证支持结论或答案切题，结果需人工复核。

失败返回交互/页面加载/网络/权限/参数等分类以及允许请求的网络错误和主动阻断记录。正文尚不可读的动作同时保存并展示具体读取原因与连接诊断，不只显示笼统状态。主文档返回但正文为空不等于零结果；权限拦截不能靠原样刷新、等待或重启解除，模型需选择合法替代路径或报告。首入口失败不直接结束，由 Kimi 决定恢复或停止；连续无进展提示循环。不同目标的连续动作失败由程序计数：连续3次给出必须改变策略的警告，连续5次强制停止并保留证据与诊断，避免空耗预算（真实任务曾连续8次换路径 404 烧掉约三成额度）。模型 API 本身失败不自动重试，由应用保存故障；取消/总预算由程序强制执行。

按需视觉截图需显式设置 `ASSISTANT_BROWSER_VISION=true`，仅提供匿名当前页且输入框遮罩，保存在忽略的 `data/screenshots/`。默认关闭；真实 Kimi 已接受一次图片+工具输入，但 DOM 同时提供了相关信息，不能据此认为视觉布局/遮挡判断已验收。

后台一次仅运行一个浏览任务，但浏览不再持有 Service 全局操作锁，期间可对话、导入、编辑记忆或分析通知；普通通知/对话之间原有串行约束仍保留，额度共用且原子预取，其他操作可能消耗任务开始时显示的日余量。取消不撤回已发起调用。进程中断后保留记录、不自动恢复；“重新发起”创建新任务、使用当前画像并重新计费，暂不原地续跑。

专用匿名会话校验导航、HTTP重定向、授权域和公网 DNS。所有网站采用相同的通用负向策略：访问域内 GET/HEAD 与正常 POST 默认允许，POST 支持空正文、JSON对象/数组、表单编码及明确文本/GraphQL查询，总正文限制64KiB，不要求端点白名单、站点分页字段或专用响应格式。浏览器识别为脚本/样式/图片/字体/媒体的 HTTPS GET/HEAD 自动允许跨域，不按 CDN 清单或文件扩展名放行；查询操作/凭据、用户禁令与非公网地址仍拒绝。额外数据域（兼容 API 字段 `resource_domains`）仅用于 GET/HEAD 数据接口，不授权页面导航或 POST。站点自产签名原样传递，不生成签名或绕过验证。自动加载第三方资源可能包含匿名统计请求，不证明所有资源无副作用，仅适合可信公开查询。

普通 GET/HEAD 阅读页不再因文章路径含 `create/delete/edit` 等词拒绝，例如 `/docs/create-react-app`、`/blog/how-to-delete-facebook-account`、`/wiki/Edit`；动作词仅提示风险。网站自己发起的 xhr/fetch GET 数据请求不做路径词或查询键判断——模型没有构造请求的工具，`/api/apply/jobs` 这类命名空间只读接口不再被误拦（格力招聘的真实失败即源于此）。POST 路径只按末段动作词判断（`/jobs/apply` 拦、`/api/apply/jobs` 放），POST 正文键名是站点数据模式不是操作（`createTime`/`updateTime`/`applyId` 等常规字段放行）。文档页的完整操作段（如 `/delete`）仍拦，操作选择器（`?action=delete`）、凭据字段与 GraphQL mutation 在任何面都拦，静态资源不按动作词拦截。路径规则是启发式，不能证明具体请求的后果。普通文章链接标题不再被按钮词表误伤，动作词标题的 href 直接导航，不触发 onclick；实际业务按钮限制保留。

凭据、操作选择器值、GraphQL mutation、文件类型正文与 PUT/PATCH/DELETE 等仍阻断。普通检索词中含“删除”不会因此拒绝搜索。Cookie 提示优先拒绝可选/仅必要，业务同意不一律放行。GET、未命中黑名单及用户阅读豁免均不证明无副作用；只用于匿名可信公开查询，不能作为任意网站或登录账号的安全沙箱。

任务表单“高级”支持额外网站/只读数据域及禁止访问 URL：最多20项任务域内的精确 HTTPS 路径，不带查询参数/片段；该路径的所有查询参数与请求方法均阻断，不是前缀或全站禁令。旧 `read_post_urls` 仅保留历史兼容，不再授予额外能力，也不能覆盖禁令。静态资源无需填写域名；看到页面或数据接口越域阻断时，不要盲目授权账号/验证码等域。旧任务已保存的资源域继续用于 GET/HEAD 数据接口。

误拦的 `path_keyword` 可通过高级区 `read_exceptions` JSON数组精确豁免，例如 `[{"url":"https://example.com/wiki/delete","method":"GET","resource_type":"document"}]`。查看保存正文的拦截记录，点击“填入阅读豁免”只准备新任务，不立即放行；起始地址的可豁免拦截也会填入候选并取消确认勾选，核实后重新发起。绑定完整 URL（包括查询参数）、GET/HEAD/POST 和 document/xhr/fetch；POST还须保留记录中的 `body_sha256` 与 `content_type`，正文变动或类型改变后豁免无效。最多20项，只解除路径启发式，不覆盖域、公网、显式禁止、查询操作、凭据/写正文/mutation/上传/方法限制；不授权实际写入，也不由模型自行添加。无法核实POST正文就不要确认。

通用 DOM 观察识别原生 onclick 与 React 点击卡片。`ready` 仅表示当前正文快照可取得，数据加载问题以 `read_warning` 保留，不因一个配置/附属请求未结束就禁止读取已显示内容；空白/文档失败仍不可引用。`body_stable` 单独报告变化，`pending_data_requests`、`data_responses`、`data_errors` 仅记录传输事实，不读取或验证站点业务 JSON。HTTP成功/快照可读不证明列表/详情已加载，Kimi 必须核对所需正文，不把空框架或业务错误当作零结果/完成。界面用“动作已执行/快照可读”而非业务成功描述这些状态。更新后重启应用并重新发起任务，历史任务不改写。

可运行 `.venv/bin/python -m tests.honor_probe` 免费检查荣耀列表、搜索与观察到的岗位详情；探测脚本保留的资源域无需再复制到网页任务，静态资源自动加载。脚本使用相同通用策略，站点字段只用于探测断言/诊断，不参与生产放行；每阶段首次真实连接失败最多免费刷新一次，保留失败证据，不算模型自主恢复。使用上述 Chromium 缓存环境变量，不调用模型、不登录或投递；每轮诊断在忽略的 `data/honor-probe/<随机标识>/`，不替代真实 Kimi 验收。

浏览器通过应用内部的任务级 HTTPS 隧道连接公网，不继承 WSL 的 HTTP_PROXY，不使用 FlClash；不修改系统代理、路由或自动切换 DNS。内部隧道仅监听随机回环端口，不要求 HTTP 代理密码、不向浏览器配置全站 HTTP 认证凭据，随任务浏览器关闭；动态解析域名并连接已检查的字面公网 IP。同会话固定解析结果，连接失败可尝试其他已检查公网地址，不重新按主机名连接。TLS 和证书验证仍由 Chromium 完成，不解密流量。系统 DNS 默认，私网/Fake-IP及混合公网/私网结果拒绝；可显式选择 `ASSISTANT_BROWSER_DNS=google` 使用固定的 [Google DNS-over-HTTPS](https://developers.google.com/speed/public-dns/docs/doh/json)，此时页面加载发现的资源域名也会发送给该 DNS 服务。换 DNS 不是稳定性保证。此连接层修正尚未实测，按用户要求交由用户运行验收。

上轮新增代理密码后，用户实测出现 `HTTP 407 / ERR_INVALID_AUTH_CREDENTIALS`，失败发生在内部代理认证、尚未进入正常网页读取；现已取消这条认证路径。若仍遇到代理认证错误，会明确报告不可原样重试的连接配置异常，而非笼统网络超时。普通连接失败保留浏览器 `net::ERR_*` 代码，不复制可能含私有参数的原始异常。导航失败后的空白/错误页不能当成可刷新的成功页面。网页登录用的 `ASSISTANT_ACCESS_TOKEN` 不受影响。

取消代理密码不等于提供多用户隔离：同机进程可连接这个临时公网中继，隧道本身不执行任务的 URL/动作权限检查（该检查仍在 Chromium 执行层），也不持有用户账号会话或解密 TLS。只用于当前本机开发；共享服务器部署需评估连接隔离与资源滥用风险，不把随机端口当认证。

## 输入、存储和记忆

网页 JSON 导入支持一个通知对象或最多 20 个对象的数组，文件最多 100KB，格式如下：

```json
{
  "source": "qq",
  "conversation": "合成课程群",
  "sender": "合成助教",
  "message_id": "synthetic-001",
  "sent_at": "2026-09-16T10:00:00+08:00",
  "text": "请于9月20日18:00前报名，活动于9月23日14:00开始。",
  "attachments": []
}
```

`sent_at` 必须带时区，表示**原消息时间**。`message_id` 可省略，没有时用来源、会话、发送者、原时间和正文组成身份。相同正文在不同时间不是重复消息。同一身份出现不同内容会报冲突，不覆盖原文。网页上的来源选择仅是标记，不表示已接入该平台。

`attachments` 只支持文本元信息列表，当前不读取文件，也不访问正文链接。单次分析/问答上下文超过 40000 字会报错，不静默截断；对话最多选择 10 条通知，未选择时使用最新 10 条。完整单会话最多 200 轮，模型只读取最近 6 轮。

私有数据默认在 `data/`：`messages/*.json`、`tasks/*.json`、`memory/profile.md`、`memory/rules.md`、`memory/history/*.json`、`chat.json` 和 `usage.json`。任务记录保留用户要求、画像/规则快照、动作、页面获取时间与受长度限制的正文、验证状态、失败和筛选结果；可在网页查看保存的证据。可以备份整个目录；当前没有自动备份、删除或保留期限管理，任务最多100条。不要存放真实资料直到你接受该保存方式。

显式记忆命令和编辑立即生效，不自动重跑旧通知。修改错误记忆时可直接编辑网页内容再保存；完整旧/新文本保留在历史快照中。记忆不能改变发送或提交权限。本版尚不从普通对话自动推断画像。

不要把密码或 Key 放入画像、规则、通知和对话；这些内容会随真实分析发送至配置的模型服务。文件仅供当前 Linux 用户访问，但同机管理员仍可能读取，不能视为完全隔离。
